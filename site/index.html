01 / THE APPROACHA NARROW JOB. AN INSPECTABLE OUTPUT.

Understand the moment.
Choose what happens next.

We adapt language models to a focused task: read the current task, environment, and recent dialogue, then select a structured decision for an external executor.

INPUT / 01

A shared picture

Task status and progress. Local environment. Recent dialogue. The player’s latest instruction.

state + conversation
DECISION / 02

A precise next step

Continue, pause, cancel, replace the task, or ask for clarification—with a skill when needed.

{ decision, skill }
EXECUTION / 03

An external executor

The surrounding agent owns game actions, cancellation, safety checks, and completion feedback.

game actions + feedback

Experimental boundary This project evaluates text-based task decisions on synthetic data. Live Minecraft behavior, in-game task success, and end-to-end latency are unvalidated.

Interpreting the 1.7B result Strict accuracy improved from 1% to 91%; decision-only accuracy improved from 33% to 91%. Schema validity rose from 1% to 99.67%, while JSON syntax stayed at 100%. The baseline returned a non-null skill for 297 nonreplacement decisions. Its low strict score therefore combines contract failures with decision errors; the gain combines schema adaptation and improved choice.

↳

Interpreting the 7B result Strict accuracy improved from 60.33% to 91%; decision-only accuracy improved from 72% to 91%. Schema validity rose from 77.33% to 100%, and JSON syntax from 88.67% to 100%. The matching 91% aggregate adapter scores do not isolate model size or establish equivalent ability across these different backends.
